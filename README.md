- **👋 Hero section** — "Hello, I'm", name, role (Web Developer | BCA Student), short intro, "Explore My Profile" + "View GitHub" buttons, profile photo.
- **🧑‍💻 About Me** — natural first-person student introduction + "At a glance" education card (no invented experience).
- **🧰 Skills** — honestly grouped: Foundational (HTML5, CSS3, C, Git & GitHub) vs Currently Learning (JavaScript, Python), with CSS level bars.
- **🎯 Hobbies & Interests** — 5 cards with inline SVG icons: coding, learning tech, web design, problem-solving, improving skills.
- **📬 Contact** — location (Baramati, Maharashtra, India) + clickable GitHub, LinkedIn, and Portfolio cards. No fake form, no invented email/phone.
- **🦶 Footer** — name, year, and internship credit.
- **🎨 Design** — white + light-blue palette, navy text, orange accents, rounded corners, subtle shadows, restrained hover states, matching "AJ" favicon + navbar logo.
- **♿ Accessible** — semantic `header`/`nav`/`main`/`section`/`footer`, single `h1`, skip link, meaningful alt text, labelled nav, good contrast.

## 🚀 How to Run

<div align="center">
  <img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=16&pause=1500&color=22c55e&center=true&vCenter=true&width=520&lines=No+npm+install...just+double-click!+%E2%9C%A8;Works+offline+%E2%80%A2+No+server+needed" alt="How to run animation" />
</div>

No install or build step. ✨

1. 📂 Open the `internship-task-2` folder.
2. 🖱️ Double-click `index.html` → opens in Chrome / Edge / Firefox.
   - Or right-click `index.html` → **Open with** → your browser.
3. 🎉 All styling loads from `style.css`; photo loads from `assets/profile.jpg`, favicon from `assets/favicon.svg` (works offline).
