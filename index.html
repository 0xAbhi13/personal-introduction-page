About Me

A student learning by building

Hi! I’m Abhishek, a first-year BCA student at Vidya Pratishthan’s Institute of Information Technology (VIIT), Baramati. I got interested in web development because I liked the idea that a few lines of code can turn into something anyone can see and use in a browser.

Right now I’m focused on the basics — writing clean HTML, styling pages with CSS, and slowly getting comfortable with JavaScript. I have also started learning C programming and Python as part of my course, which is helping me understand how programming works in general.

I learn best by doing, so I try to build small practice projects, solve beginner problems, and use Git and GitHub to keep track of my work. I’m still at the beginning of my journey, and I’m excited to keep improving one project at a time.
